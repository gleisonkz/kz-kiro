# Agents — Archetype Backend C#

> **Agents | Archetype: backend-csharp | Versão: 0.1.0**
>
> Este diretório conterá os agents customizados do Kiro para projetos de serviços de domínio .NET/C#.

---

## Propósito

Os agents são assistentes especializados do Kiro configurados para tarefas específicas do archetype. Cada agent tem um contexto, capacidades e comportamentos definidos.

---

## Agents Planejados

| Agent | Especialidade | Capacidades | Status |
|---|---|---|---|
| `domain-modeler` | Modelagem de domínio DDD | Propor entidades, value objects, aggregates e eventos | Não implementado |
| `architecture-reviewer` | Revisão de Clean Architecture | Validar Dependency Rule, fronteiras de camada | Não implementado |
| `api-designer` | Design de APIs REST | Revisar endpoints, contratos OpenAPI, versionamento | Não implementado |
| `test-writer` | Geração de testes | Gerar testes unitários e de integração | Não implementado |
| `migration-reviewer` | Revisão de migrations | Validar backward-compatibility, expand-contract | Não implementado |
