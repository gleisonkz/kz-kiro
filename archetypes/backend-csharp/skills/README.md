# Skills — Archetype Backend C#

> **Skills | Archetype: backend-csharp | Versão: 0.1.0**
>
> Este diretório contém as skills customizadas do Kiro para projetos de serviços de domínio .NET/C#.

---

## Propósito

Skills são capacidades específicas que o Kiro pode executar em projetos backend C#, como geração de código, análise de padrões ou scaffolding de módulos.

---

## Skills Disponíveis

| Skill | Descrição | Status |
|---|---|---|
| `generate-module` | Gera um módulo completo (endpoint, command/query, handler, validator, entity, repository) | Implementado |
| `generate-endpoint` | Gera um endpoint Minimal API com documentação OpenAPI | Implementado |
| `generate-repository` | Gera um repository com interface e implementação EF Core | Implementado |
