# Agents — Archetype BFF Fastify

> **Agents | Archetype: bff-fastify | Versão: 0.1.0**
>
> Este diretório conterá os agents customizados do Kiro para projetos BFF Fastify.

---

## Propósito

Os agents são assistentes especializados do Kiro configurados para tarefas específicas do archetype. Cada agent tem um contexto, capacidades e comportamentos definidos.

---

## Agents Planejados

| Agent | Especialidade | Capacidades | Status |
|---|---|---|---|
| `bff-architect` | Design de módulos e agregação | Propor estrutura de módulos, revisar padrões de agregação | Não implementado |
| `bff-api-designer` | Design de contratos de API | Revisar schemas TypeBox, sugerir melhorias de DX para o frontend | Não implementado |
| `bff-resilience-reviewer` | Resiliência e observabilidade | Revisar circuit breakers, timeouts, retry, logs e tracing | Não implementado |
| `bff-test-writer` | Geração de testes | Gerar testes unitários para mappers e de integração para rotas | Não implementado |
