# Skills — Archetype BFF Fastify

> **Skills | Archetype: bff-fastify | Versão: 0.1.0**
>
> Este diretório contém as skills customizadas do Kiro para projetos BFF Fastify.

---

## Propósito

Skills são capacidades específicas que o Kiro pode executar em projetos BFF Fastify, como geração de código, análise de padrões ou scaffolding de módulos.

---

## Skills Disponíveis

| Skill | Descrição | Status |
|---|---|---|
| `generate-module` | Gera um módulo BFF completo (routes, handlers, schemas, service, mapper, client) | Implementado |
| `generate-client` | Gera um client HTTP para serviço downstream com retry e circuit breaker | Implementado |
| `generate-plugin` | Gera um plugin Fastify encapsulado | Implementado |
