# Steering — Archetype Frontend React

> **Steering File | Archetype: frontend-react | Versão: 0.1.0**
>
> Este arquivo é injetado como contexto pelo Kiro em projetos que utilizam o archetype frontend-react.
> Ele complementa o baseline global com diretrizes específicas para projetos React.

---

## Steering Files Disponíveis

| Arquivo | Conteúdo | Fontes |
|---|---|---|
| `stack-and-tooling.md` | Stack base, ferramentas, monorepo, workspaces | ADR-0001, RFC-0001, RFC-0002 |
| `architecture.md` | Monolito modular, fronteiras, organização por feature | ADR-0003, RFC-0003 |
| `design-system.md` | Arquitetura DS, tokens, Base UI, Storybook, qualidade | ADR-0005, ADR-0008, RFC-0005 a RFC-0009 |
| `naming-conventions.md` | Convenções de nomenclatura para código, arquivos e diretórios | Convenções de Nomenclatura (Confluence) |
| `ci-cd.md` | Pipelines, deploy independente, orquestração por impacto | RFC-0004 |

## Relação com o Baseline Global

Estes steering files complementam (não substituem) o baseline global:

- `engineering-principles.md` — princípios gerais de engenharia
- `security-baseline.md` — requisitos mínimos de segurança
- `specs-policy.md` — política de especificações
- `documentation-baseline.md` — padrão de documentação
