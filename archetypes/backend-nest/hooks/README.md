# Hooks — Archetype Backend NestJS

> **Hooks | Archetype: backend-nest | Versão: 0.1.0**
>
> Este diretório conterá os hooks do Kiro específicos para projetos NestJS.

---

## Propósito

Os hooks permitem customizar o comportamento do Kiro em momentos específicos do fluxo de desenvolvimento (ex.: antes de um commit, após uma geração de código, ao abrir um arquivo).
