# Hooks — Frontend Angular

| Hook | Trigger | Ação |
|------|---------|------|
| `kiro-doctor` | `userTriggered` | Verifica saúde do projeto (lint, build, test) |
| `lint-after-agent` | `agentStop` | Roda lint após execução do agente |
| `run-tests-after-task` | `postTaskExecution` | Roda testes após tarefa de spec concluída |
