# mb-mobile-flutter

> **Power | mb-mobile-flutter | Versão: 0.1.0**

## Visão Geral

O `mb-mobile-flutter` é o power de capacidades operacionais para projetos Flutter mobile da MonteBravo. Ele complementa o archetype `mobile-flutter` com orientações práticas do dia a dia: debugging, padrões de teste, Design System mobile e convenções específicas do Flutter.

## Instalação

Este power é instalado automaticamente pelo `bootstrap.sh` em projetos do tipo `mobile-flutter`.

## Capacidades

| Capacidade | Tipo | Descrição | Status |
|---|---|---|---|
| Geração de feature Clean Architecture | Skill | Cria feature completa (domain, data, presentation) | Não implementado |
| Revisão de arquitetura | Agent | Analisa camadas e dependências entre features | Não implementado |
| Auditoria de imports | Agent | Verifica uso de imports absolutos `package:` | Não implementado |
| Geração de use case | Skill | Cria use case com teste e mock | Não implementado |

## Diferença do archetype

O archetype define as **regras e padrões** (o que fazer). Este power define as **práticas operacionais** (como fazer no dia a dia).
